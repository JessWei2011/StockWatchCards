一、使用者目標
--------------

建立一個可由 iPhone Safari 直接透過網址瀏覽的「個股分析中心手機版」。

第一階段只發布一檔股票：

  5. RSI

------------

  mobile_web/
    package.json

    src/
      worker.js                 Cloudflare Worker 入口與密碼驗證

      modules/
        parser.js               由現有 parser.js 複製或共用

重要原則：

  - 不部署任何股票 API 金鑰。
  - 不讓手機呼叫 PC localhost。
  - 不把整個 reports/ 上傳，只上傳雙鴻需要的檔案。
  - 每次發布前由 export_mobile_site.py 重新覆寫輸出快照。


六、密碼保護建議
----------------

不要只在前端 JavaScript 寫明文密碼，因為任何人都可檢視原始碼。

建議使用 Cloudflare Worker HTTP Basic Authentication，或 Worker 自訂登入 Cookie。

第一階段最簡單可靠方案：HTTP Basic Authentication。

  - Wrangler secret 名稱：SITE_USERNAME
  - Wrangler secret 名稱：SITE_PASSWORD
  - 帳密不要寫進 Git、HTML、JS、wrangler.jsonc 或本文件。
  - Worker 先檢查 Authorization header，通過後才回傳靜態資源。
  - 未通過回傳 401，並附 WWW-Authenticate header。
  - 密碼由使用者指定，或由接手 AI 產生高強度隨機密碼後私下交付。

注意：若使用 Cloudflare Assets binding，必須確認所有靜態資源請求都先經過 Worker 驗證，
不可讓 public 資產存在可繞過驗證的公開路徑。


七、匯出程式 export_mobile_site.py
--------------------------------

必須使用專案 AGENTS.md 指定 Python：

  C:\Users\User\AppData\Local\Programs\Python\Python311\python.exe

不要使用 python、python3、py 或 PATH 探測。

匯出流程：

  1. 讀取 data.js。
  2. 使用與 reports_manager_server.py 相同概念的正規表示式擷取 STOCK_CARDS JSON。
  3. 篩選 code == "3324"。
  4. 若有多筆，依 date 選最新一筆。
  5. 尋找 reports/**/3324_*.html。
  6. 若有多份，以 mtime 最新者為主，但處置期間舊報告不得蓋過正式最新版。
     最好沿用 reports_manager_server.py 的 TRACKED_FILENAME_RE 與 build_reports_index 規則。
  7. 找出對應的 3324_*_4階段技術分析報告.md。
  8. 將卡片資料寫為 UTF-8 JSON：mobile_web/public/data/stock.json。
  9. 將報告 HTML 複製成固定英文檔名 report.html，避免部署路徑與中文 URL 問題。
  10. 將 Markdown 複製為 analysis.md。
  11. 產生 manifest.json，內容至少包含：

      {
        "version": 1,
        "code": "3324",
        "name": "雙鴻",
        "market": "TWO",
        "analysisDate": "卡片日期",
        "publishedAt": "ISO 8601 +08:00",
        "sourceReport": "原始相對路徑"
      }

  12. 匯出後驗證必要檔案存在且非空。
  13. 若找不到雙鴻資料、HTML 報告或 K 線表格，立即失敗，不可發布空頁。


八、手機頁面需求
----------------

頁面採 mobile-first，iPhone Safari 為主要目標。

首頁可以直接就是雙鴻詳情，不必先做 73 檔清單。

建議畫面順序：

  1. 頂部：3324 雙鴻、資料日期、最後發布時間
  2. 決策摘要卡：評分、決策、型態、信心度
  3. 價位卡：現價、買進、停損、壓力
  4. K 線圖工具列：
       - 顯示／隱藏均線
       - 顯示／隱藏布林
       - 20 日／60 日／全部
       - 全螢幕
  5. 互動圖表：K 線、成交量、RSI、MACD、KD
  6. 最新技術指標數值摘要
  7. 支持進場證據／反對進場證據
  8. 最終持股建議
  9. 可折疊完整四階段報告
  10. 可折疊原始數據表格（需要時才展開）

手機互動要求：

  - 圖表可單指橫向拖曳。
  - 可雙指縮放或使用 dataZoom。
  - 十字游標顯示日期、OHLC、量與指標值。
  - 按鈕至少 44px 高，避免 iPhone 難以點擊。
  - 不允許整頁產生不必要的水平捲軸。
  - K 線區域建議高度至少 620px；五區圖若太擠，可提供「主圖／指標」切換。
  - 支援 iPhone 安全區：env(safe-area-inset-top/bottom)。
  - 深色主題沿用目前分析中心。
  - 台股配色：上漲紅、下跌綠。

--------------------------------------

目前尚未完成 Cloudflare OAuth 授權。

系統 PATH 沒有 node、npm、npx、wrangler。
Codex 內建可用 Node：

  C:\Users\User\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe

Codex 內建 pnpm：

  C:\Users\User\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd

嘗試 pnpm dlx wrangler@4 login 時遇到 pnpm 相依解析問題：

  - wrangler 最新版缺少 undici
  - 固定 wrangler 4.46.0 後缺少 exit-hook
  - 即使以 pnpm dlx 額外指定套件，Miniflare 仍無法解析 exit-hook

已建立但尚未安裝依賴的檔案：

  mobile_web/package.json

內容固定：wrangler 4.46.0、undici 7.16.0、exit-hook 4.0.0。

建議接手方式：

  - 在 mobile_web 目錄執行正式 pnpm install，而不是 pnpm dlx。
  - 可嘗試 pnpm install --shamefully-hoist，避免 Miniflare 找不到相依。
  - 再執行 pnpm run cloudflare:login。
  - 若仍失敗，改用 Cloudflare Dashboard 的 Direct Upload，或使用獨立 npm 安裝環境。
  - 不要重複要求使用者提供 Cloudflare 密碼。
